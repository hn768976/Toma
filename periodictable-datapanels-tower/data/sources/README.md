# Element data sources

`data/elements.csv` is generated by `npm run data:build` (scripts/build-elements.mjs)
from the files in this folder and checked by `npm run data:check`.

| File | Used for | Origin |
|---|---|---|
| `ciaaw-abridged-and-oxidation.csv` | atomic masses, common oxidation states | Masses: CIAAW/IUPAC abridged standard atomic weights (5 significant figures, current through the 2024 revision: Zr 91.222). Elements with no stable isotopes show the mass number of the longest-lived isotope in brackets, e.g. Tc [98], Og [294]. Oxidation states: the commonly cited ("main") states, curated. |
| `PeriodicTableJSON.json` | names, categories, blocks, electron configurations and shells | Bowserinator/Periodic-Table-JSON (fetched once and saved). Current IUPAC names for 111–118 (Rg, Cn, Nh, Fl, Mc, Lv, Ts, Og). |
| `pubchem-legacy-elements.csv` | cross-check of symbols only | PubChem-format element table (andrejewski/periodic-table). |

Notes

- The brief asked for PubChem as the name/category/configuration source.
  PubChem's REST endpoint was not reachable from the build environment
  (the network proxy refused the host), so the saved PeriodicTableJSON file
  was used instead and cross-checked against a PubChem-format table. The
  values that matter on the tiles (names, masses, shells, layout) are all
  verified by `npm run data:check`.
- Electron shells are derived from each element's electron configuration so
  the two always agree. Ds and Rg use the relativistic predicted ground states
  (6d8 7s2, 6d9 7s2).
- Spelling: `name` is IUPAC (Aluminium, Caesium), `name_us` is US. The switch
  is one line in `src/config.ts`.
- Layout (`row`, `col`) is computed from Z: standard 18 columns, lanthanides
  (57–71) and actinides (89–103) in rows 9 and 10 starting under group 3, and
  group 3 of periods 6–7 left empty on the main table.
