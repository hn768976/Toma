# remotion-lib

Shared Remotion components. See CATALOG.md.

These are source files, not a published package: copy the ones you need into
your project's `src/` (so a project zip stays standalone) or add this
directory to your bundler's resolve paths. Peer requirements: `react` and
`remotion` v4+.

This copy is committed here so the library survives the ephemeral session
container it was authored in. The canonical working location is
`~/projects/remotion-lib`.
