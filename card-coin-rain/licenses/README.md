| File | What | Licence |
|------|------|---------|
| `public/fonts/Inter-Regular.woff2`, `public/fonts/Inter-Medium.woff2` | Inter typeface (latin subset, from `@fontsource/inter` 5.3.0) | SIL Open Font License 1.1 — `Inter-OFL-1.1.txt` |
| `public/hdri/studio_small_03_1k.hdr` | Poly Haven "Studio Small 03" HDRI | CC0 1.0 — `HDRI-studio_small_03-CC0.txt` |

Everything else visible on screen is generated in code at load time from
deterministic noise: the crinkled-foil, brushed, hammered and coin (reeded edge)
normal/roughness maps, the chip contact pattern, and the card print (rendered
from Inter into a 4096-px canvas). No textures, logos, currency designs, card
network marks or refinery stamps are used.
