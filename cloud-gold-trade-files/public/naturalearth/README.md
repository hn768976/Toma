# Natural Earth data

`ne_50m_admin_0_countries.geojson`: Natural Earth 1:50m Cultural Vectors,
Admin 0 – Countries, **default worldview**, as published at
https://github.com/nvkelso/natural-earth-vector (geojson/), version on master at
build time. Public domain; see LICENSE.md in this folder
(https://www.naturalearthdata.com/about/terms-of-use/).

"Made with Natural Earth. Free vector and raster map data @ naturalearthdata.com."

Countries are selected by their `ADM0_A3` code (e.g. USA, CHN, CAN, JPN, DEU,
FRA, ITA). The largest polygon of each country is used, which gives the
contiguous United States for USA and mainland China for CHN.
