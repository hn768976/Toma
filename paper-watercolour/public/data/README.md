# Map data

`ne_50m_land.geojson` is **Natural Earth 1:50m Land** (physical/land polygons
only — coastlines, no country borders), downloaded from
https://github.com/nvkelso/natural-earth-vector (geojson/ne_50m_land.geojson).

Natural Earth data is in the **public domain** (see `NATURAL_EARTH_LICENSE.md`).
No permission or credit is required. Optional credit: "Made with Natural Earth."
