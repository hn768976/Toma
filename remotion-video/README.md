grades) — is documented separately in [SPIRAL_FLOW.md](./SPIRAL_FLOW.md).

## Commands

**Install Dependencies**

```console
npm i
```

**Start Preview**

```console
npm run dev
```

**Render video**

```console
npx remotion render
```

**Upgrade Remotion**

```console
npx remotion upgrade
```
