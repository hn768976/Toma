## VFX overlay plates

This project contains four seamlessly looping VFX overlay plates (dust, rain,
smoke, snow), rendered with PixiJS v8 and custom WebGL2 fragment shaders, each
available as a 4K master and a 1080p delivery composition.

See **[PLATES.md](./PLATES.md)** for the plate list, the looping technique, the
render flags and the tweakable props.

```console
npm run render:plates       # 1080p deliverables
npm run render:plates:4k    # 4K masters
```

## Commands

**Install Dependencies**

```console
npm i
```

**Start Preview**

```console
npm run dev
```

**Render video**

```console
npx remotion render
```

**Upgrade Remotion**

```console
npx remotion upgrade
```
