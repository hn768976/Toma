# Toma — light-texture plates

Remotion project containing four abstract background plates, each a
procedural recreation of a supplied stock reference clip. Nothing is
filmed, sampled or rotoscoped: every frame is generated by a custom GLSL
fragment shader running through PixiJS v8 inside Remotion.

## The plates

| Composition | 4K variant | Length @30fps | Look |
|---|---|---|---|
| `GoldenRays` | `GoldenRays4K` | 420f / 14.000s | Sun through foliage — blown gold core, crepuscular shafts, olive greens |
| `SilverBokeh` | `SilverBokeh4K` | 570f / 19.000s | High-key silver bokeh on a near-white field |
| `DeepBlueDust` | `DeepBlueDust4K` | 390f / 13.000s | Deep navy, ringed blue bokeh, twinkling dust |
| `BokehCurtain` | `BokehCurtain4K` | 300f / 10.000s | Defocused string-light curtain, amber and steel blue |

All four are **seamless loops** and all four are silent, matching the
references. `<Name>` renders 1920×1080; `<Name>4K` renders 3840×2160 from
the same component and the same props.

Design and technique are documented in [`src/plates/README.md`](src/plates/README.md).
Delivery measurements are in [`docs/plates-verification.md`](docs/plates-verification.md).

## Quick start

```console
npm i
npx remotion studio
```

The Studio exposes every plate's palette and behaviour as typed props, so
they can be scrubbed live. `seed` reshuffles disc placement, sizes and
twinkle phases without altering the motion design — the fastest way to get
a different take on the same look.

## Rendering

```console
npx remotion render GoldenRays   out/GoldenRays_1080p.mp4 --codec=h264 --crf=16 --pixel-format=yuv420p --image-format=png
npx remotion render GoldenRays4K out/GoldenRays_2160p.mp4 --codec=h264 --crf=16 --pixel-format=yuv420p --image-format=png
```

Two flags matter:

- **`--image-format=png`** — these plates are almost entirely smooth
  gradient, exactly what JPEG intermediates band and block on. Remotion's
  default JPEG quality leaves visible artefacts in the bokeh falloff.
- **`--crf=16`** — same reasoning; large flat gradients need the headroom.

### GPU

`remotion.config.ts` ends with:

```ts
Config.setChromiumOpenGlRenderer("swangle");
```

That points headless Chrome at ANGLE's SwiftShader backend, so a real GL2
context exists on a machine with no GPU. It is a **software** rasteriser
and it is slow — roughly 1.3s per 1080p frame on four cores, which makes a
4K pass impractical.

**On any machine with a GPU, delete that line.** The 4K compositions then
render at normal speed. They are correct and validated either way: a 4K
still downsampled to 1080p differs from the native 1080p still by 0.09/255.
