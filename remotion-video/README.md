## Molecular Dreams (nine versions)

Nine three.js/WebGL motion pieces built on `public/models/molecule.glb`, each
staged after one supplied reference clip. 30fps, H.264/MP4, registered at both
1080p and 4K.

```console
npm run render:1080     # all nine -> out/1080p
npm run render:4k       # all nine at 3840x2160 -> out/4k
```

See [`src/molecular/README.md`](./src/molecular/README.md) for the version list,
why the look is material-driven rather than texture-driven, and the notes on
keeping renders deterministic.

## Commands

**Install Dependencies**

```console
npm i
```

**Start Preview**

```console
npm run dev
```

**Render video**

```console
npx remotion render
```

**Upgrade Remotion**

```console
npx remotion upgrade
```
