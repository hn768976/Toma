# Night-lights texture

`black-marble-2012-4096.jpg` — **NASA Earth Observatory "Black Marble" (2012)**, night lights
composite from Suomi NPP VIIRS day/night band (image by NASA Earth Observatory/NOAA NGDC).
NASA imagery is public domain (not subject to copyright in the US).

Retrieved as the 4096x2048 equirectangular copy mirrored in the `vasturiano/three-globe`
repository (`example/img/earth-night.jpg`), because NASA's own image hosts were not
reachable from the build environment. Swap in a higher-resolution Black Marble
(e.g. 8K/13.5K from earthobservatory.nasa.gov / visibleearth.nasa.gov) for sharper 4K
close-ups; no code changes needed if the file name is kept.
