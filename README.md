# Lightning Strike — 4K Remotion animations

Three atmospheric lightning variants in one Remotion project, all 3840 × 2160,
300 frames @ 30 fps (10.0 s), seamlessly looping.

| Composition | Condition | Bolt structure |
| --- | --- | --- |
| `LightningBlue` | distant strike, clean air | one descending channel, 3-5 forks low down |
| `LightningViolet` | hazy air scattering short wavelengths | 2-3 simultaneous chaotic channels, heavily branched |
| `LightningWhite` | very close strike | one upward channel, sparse forks, whole-frame flash |

## Render

1080p previews:

```bash
npx remotion render LightningBlue   out/lightning-blue-preview.mp4   --codec=h264 --crf=18 --scale=0.5
npx remotion render LightningViolet out/lightning-violet-preview.mp4 --codec=h264 --crf=18 --scale=0.5
npx remotion render LightningWhite  out/lightning-white-preview.mp4  --codec=h264 --crf=18 --scale=0.5
```

Full 4K:

```bash
npx remotion render LightningBlue   out/lightning-blue.mp4   --codec=h264 --crf=12 --concurrency=8
npx remotion render LightningViolet out/lightning-violet.mp4 --codec=h264 --crf=12 --concurrency=8
npx remotion render LightningWhite  out/lightning-white.mp4  --codec=h264 --crf=12 --concurrency=8
```

## Standalone projects

`dist/` holds three self-contained zips — `lightning-blue.zip`,
`lightning-violet.zip`, `lightning-white.zip` — each an independently runnable
Remotion project registering only its own composition, with that variant's
configuration inlined. Rebuild them with `node scripts/make-zips.mjs`.

## Architecture

`src/variants.ts` is the single source of every colour and timing number:
palette, bolt generation parameters, strike schedule, flash profile, ambient
settings and finish, per variant. Nothing else contains a hex literal or a
frame count.

Bolts are generated by recursive midpoint displacement (see
`src/lightning/geometry.ts`): each segment's midpoint is displaced
perpendicular by a seeded amount, halves recurse with the amplitude halved,
and branches spawn from midpoints, recursing one level shallower, dimmer and
thinner each generation. `strikeDirection` in the config is signed — every
generated point maps through it, so the white variant's upward travel (and its
inverted taper) comes from `-1` alone.

Each bolt renders in four additive passes — wide atmospheric glow, outer glow,
mid channel, thin near-white core — with the blurred halos drawn on a
quarter-size companion canvas (`src/lightning/surface.tsx`) and composited up.

Everything is a pure function of `useCurrentFrame()`, and all randomness runs
through Remotion's `random()` with stable string seeds, so renders are
deterministic and frame 0 equals frame 300 exactly.
