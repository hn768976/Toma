# Composition 2 — Ripple Surface (Remotion, WebGL 2 shader)

Procedural grey water surface: groups of thin bright crest lines from
expanding concentric ripples (centres mostly outside the frame), bending and
kinking where wave trains cross, over a soft mid-grey base. Everything is
generated by a single GLSL ES 3.00 fragment shader (`src/shaders/ripple.ts`)
drawn into a WebGL 2 canvas (`src/ShaderCanvas.tsx`). No external image or
video assets are used.

| Composition id                    | Size      | FPS | Frames | Duration | Camera                                      |
| --------------------------------- | --------- | --- | ------ | -------- | ------------------------------------------- |
| `RippleSurface-V1-Reference`      | 3840×2160 | 30  | 540    | 18.000 s | Orthographic top-down (matches reference)   |
| `RippleSurface-V2-LowAngleDolly`  | 3840×2160 | 30  | 540    | 18.000 s | Low-angle perspective, slow dolly + pan     |

The reference clip is 540 frames at 29.97 fps (18.018 s). At an exact 30 fps
the frame count is kept identical (540 frames = 18.000 s). The reference's
audio track is pure digital silence (−91 dB), so no audio is produced.

Version 2 evaluates exactly the same water simulation and shading; only the
camera changes (ray–plane intersection with a perspective camera ~24° below
the horizon that dollies forward and pans ~30° over the shot, with distance
haze and band-limiting to avoid aliasing).

## Requirements

- Node.js 20.19+ or 22.13+ (tested with Node 22)
- ~2 GB free disk for `node_modules` and Remotion's headless browser

## Commands

```console
npm ci                       # install exact dependency versions
npm run dev                  # Remotion Studio preview

# 1080p H.264 deliverables (4K composition rendered at scale 0.5)
npx remotion render RippleSurface-V1-Reference     out/Composition2_V1_Reference_1080p.mp4     --scale=0.5
npx remotion render RippleSurface-V2-LowAngleDolly out/Composition2_V2_LowAngleDolly_1080p.mp4 --scale=0.5

# Native 4K masters (optional)
npx remotion render RippleSurface-V1-Reference     out/Composition2_V1_Reference_4K.mp4
npx remotion render RippleSurface-V2-LowAngleDolly out/Composition2_V2_LowAngleDolly_4K.mp4

npm run lint                 # eslint + tsc
```

Codec settings (H.264, yuv420p, CRF 16, x264 preset `slow`) and the OpenGL
backend live in `remotion.config.ts`.

### GPU vs. CPU rendering

`remotion.config.ts` selects `swangle` (SwiftShader software WebGL), which
works on any machine including GPU-less servers; it takes ~2–3 s per 4K frame
on 4 CPU cores. On a machine with a GPU you can add `--gl=angle` to the
render command for a much faster render — the output is identical in look.

## Project structure

```
src/
  index.ts            registerRoot
  Root.tsx            the two 4K compositions
  RippleSurface.tsx   component: camera mode -> shader uniforms
  ShaderCanvas.tsx    reusable WebGL 2 full-frame shader layer
  constants.ts        size / fps / duration / camera modes
  shaders/ripple.ts   GLSL fragment shader
```

Each frame is a pure function of `frame / fps`, so rendering is deterministic
and can run with any `--concurrency`.
