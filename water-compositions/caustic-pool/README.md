# Composition 1 — Caustic Pool (Remotion, WebGL 2 shader)

Procedural, top-down pool-water caustics: dark-blue blotches separated by a
smeared, bright cyan caustic network, with a persistent sun-glow toward the
top of frame. Everything is generated by a single GLSL ES 3.00 fragment shader
(`src/shaders/caustic.ts`) drawn into a WebGL 2 canvas (`src/ShaderCanvas.tsx`).
No external image or video assets are used.

| Composition id                  | Size      | FPS | Frames | Duration | Notes                                   |
| ------------------------------- | --------- | --- | ------ | -------- | --------------------------------------- |
| `CausticPool-V1-Reference`      | 3840×2160 | 30  | 480    | 16.000 s | Matches the reference (pool blue/cyan)  |
| `CausticPool-V2-EmeraldLagoon`  | 3840×2160 | 30  | 480    | 16.000 s | Same motion, emerald / mint / pale-gold palette |

The reference clip is 480 frames at 29.97 fps (16.016 s). At an exact 30 fps
the frame count is kept identical (480 frames = 16.000 s).

## Requirements

- Node.js 20.19+ or 22.13+ (tested with Node 22)
- ~2 GB free disk for `node_modules` and Remotion's headless browser

## Commands

```console
npm ci                       # install exact dependency versions
npm run dev                  # Remotion Studio preview

# 1080p H.264 deliverables (4K composition rendered at scale 0.5)
npx remotion render CausticPool-V1-Reference     out/Composition1_V1_Reference_1080p.mp4     --scale=0.5
npx remotion render CausticPool-V2-EmeraldLagoon out/Composition1_V2_EmeraldLagoon_1080p.mp4 --scale=0.5

# Native 4K masters (optional)
npx remotion render CausticPool-V1-Reference     out/Composition1_V1_Reference_4K.mp4
npx remotion render CausticPool-V2-EmeraldLagoon out/Composition1_V2_EmeraldLagoon_4K.mp4

npm run lint                 # eslint + tsc
```

Codec settings (H.264, yuv420p, CRF 16, x264 preset `slow`) and the OpenGL
backend live in `remotion.config.ts`.

### GPU vs. CPU rendering

`remotion.config.ts` selects `swangle` (SwiftShader software WebGL), which
works on any machine including GPU-less servers; it takes ~2–3 s per 4K frame
on 4 CPU cores. On a machine with a GPU you can add `--gl=angle` to the
render command for a much faster render — the output is identical in look.

## Project structure

```
src/
  index.ts            registerRoot
  Root.tsx            the two 4K compositions
  CausticPool.tsx     component: palette props -> shader uniforms
  ShaderCanvas.tsx    reusable WebGL 2 full-frame shader layer
  constants.ts        size / fps / duration / palettes
  shaders/caustic.ts  GLSL fragment shader
```

Each frame is a pure function of `frame / fps`, so rendering is deterministic
and can run with any `--concurrency`.
