# Vendored from remotion-lib

Everything in `src/lib/` and the following files in `src/components/` are
copies of `~/projects/remotion-lib` (see its `CATALOG.md`), kept here so this
project is standalone:

- `components/PerspectiveCorridor.tsx`
- `components/CorridorBackdrop.tsx`
- `components/HorizonGlow.tsx`
- `components/BokehLayer.tsx`
- `components/FinishPass.tsx`

They are byte-identical to the library versions. Fix bugs in the library first,
then re-copy — do not edit these in place.

Project-specific and NOT in the library: `Corridor.tsx`, `variants.ts`,
`components/FibreStrand.tsx`, `components/SlabPanel.tsx`,
`components/CorridorEdgeLines.tsx`, `components/BlockCluster.tsx`,
`components/BinaryColumn.tsx`.
