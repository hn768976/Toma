# Breathing Guide Ring

A slowly expanding and contracting ring that paces a breathing exercise: a soft
gradient body, a faint guide track at the ring's maximum extent, and a bright
progress marker that travels one full revolution per breath cycle.

Each composition is **one complete cycle that loops seamlessly**, so it can be
looped to any session length. The timing is the point — every phase is an exact
whole number of frames, so a ten-minute loop does not drift against a voiceover.

## Versions

| Composition id            | Pattern                                          | Cycle length          |
| ------------------------- | ------------------------------------------------ | --------------------- |
| `V1-BreathingBox4444`     | Box breathing — inhale 4s, hold 4s, exhale 4s, hold 4s | **16s = 480 frames** |
| `V2-Breathing478`         | 4-7-8 — inhale 4s, hold 7s, exhale 8s            | **19s = 570 frames**  |
| `V3-BreathingCoherent55`  | Coherent breathing — inhale 5.5s, exhale 5.5s, no holds | **11s = 330 frames** |

All at **3840×2160, 30 fps**.

## Setup

```bash
npm install
npx remotion studio
```

## Rendering at 4K

Compositions are defined at 3840×2160, so `--scale=1` is a native 4K render:

```bash
npx remotion render V1-BreathingBox4444    out/V1_BreathingBox4444.mp4    --scale=1 --crf=16 --muted
npx remotion render V2-Breathing478        out/V2_Breathing478.mp4        --scale=1 --crf=16 --muted
npx remotion render V3-BreathingCoherent55 out/V3_BreathingCoherent55.mp4 --scale=1 --crf=16 --muted
```

`--muted` keeps the file video-only; drop it if your pipeline expects a silent
audio track. H.264 / `yuv420p` / 30 fps come from `remotion.config.ts`.

1080p previews are the same commands with `--scale=0.5`.

Stills at peak inhale (the end of the first inhale phase):

```bash
npx remotion still V1-BreathingBox4444    out/V1_BreathingBox4444_peak.png    --frame=120 --scale=1
npx remotion still V2-Breathing478        out/V2_Breathing478_peak.png        --frame=120 --scale=1
npx remotion still V3-BreathingCoherent55 out/V3_BreathingCoherent55_peak.png --frame=165 --scale=1
```

## Props

Set per composition in `src/Root.tsx`, or live in the Studio's props panel.

| Prop              | Default | Notes                                                                       |
| ----------------- | ------- | --------------------------------------------------------------------------- |
| `pattern`         | —       | `{ id, name, steps: [{ phase, seconds }] }`. A new pattern is a data change. |
| `showPhaseLabels` | `false` | `INHALE` / `HOLD` / `EXHALE` inside the ring, fading between phases.         |
| `showEchoRings`   | `true`  | Faint rings that expand and fade on the inhale only.                         |
| `grainOpacity`    | `0.02`  | Fine grain. Keeps the dark gradient from banding in H.264.                   |

Leave `showPhaseLabels` off for the stock renders — words in the plate make the
clip single-market, and buyers overlay their own language. Turn it on for a
labelled variant.

## Adding a pattern

Add it to `src/patterns.ts` and register a `<Composition>` in `src/Root.tsx`:

```ts
export const EQUAL_6_6: BreathingPattern = {
  id: "equal-6-6",
  name: "Equal breathing 6-6",
  steps: [
    { phase: "inhale", seconds: 6 },
    { phase: "exhale", seconds: 6 },
  ],
};
```

`cycleDurationInFrames()` throws if a phase — or the cycle — is not a whole
number of frames at the composition's fps, which is what keeps the timing exact.

## Notes

- Everything is a pure function of `useCurrentFrame()`; no state, no timers, so
  frames render identically in any order on a render farm.
- The radius is computed in floating point and never rounded — stepping is
  visible on a shape this slow.
- During a hold the radius is completely still. Only the fill brightness drifts,
  by about 1.5%.
- `public/grain.png` is generated by `node scripts/make-grain.mjs` (deterministic).
- Sizes are fractions of the frame height, so the 1080p preview is an exact
  scale of the 4K render.
- This is a visual pacer, not medical guidance. Nothing in the clip makes a
  health claim, and the absence of text keeps it that way.
